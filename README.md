# CheckLab Engine - SaaS Platform

**Современная SaaS платформа для автоматизации лабораторных работ в IT-колледжах Казахстана**

![Version](https://img.shields.io/badge/version-2.0.0-blue)
![Python](https://img.shields.io/badge/python-3.9+-green)
![Flask](https://img.shields.io/badge/flask-2.3+-red)

## 🎯 О проекте

CheckLab Engine SaaS - это облачная платформа для автоматизации создания, выполнения и проверки лабораторных работ в учебных заведениях. Платформа построена на принципах мультитенантности, где каждая организация работает в изолированной среде.

## 🆕 Что нового в SaaS версии?

### ✨ Новые возможности

- 🌐 **Маркетинговый лендинг** - профессиональная главная страница с информацией о продукте
- 🏢 **Мультитенантность** - поддержка множества организаций в одной системе
- 👥 **Роль администратора** - управление организацией и просмотр статистики
- 📊 **Расширенная статистика** - метрики по всей платформе
- 📝 **Система заявок (Leads)** - форма обратной связи на лендинге
- 🎨 **Современный дизайн** - полностью переработанный интерфейс
- 💼 **Тарифные планы** - Free, Basic, Premium (готовая структура)
- 📈 **Showcase клиентов** - демонстрация учебных заведений

### 🔄 Улучшения архитектуры

- Разделение статики на CSS и JS папки
- Улучшенная структура базы данных
- Оптимизированные SQL-запросы
- Готовность к масштабированию

## 🚀 Быстрый старт

### Требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)

### Установка

1. **Клонируйте или скачайте проект**

```bash
cd checklab_saas
```

2. **Установите зависимости**

```bash
pip install -r requirements.txt
```

3. **Инициализируйте базу данных**

```bash
python init_db.py
```

Вывод:
```
============================================================
Инициализация CheckLab Engine SaaS
============================================================
✓ База данных инициализирована!
✓ Демо-данные созданы:
  Организаций: 5 (4 клиента + 1 тестовая)
  Пользователей: 4 (1 admin, 1 teacher, 2 students)

  Тестовые аккаунты:
  - Админ: admin / admin123
  - Преподаватель: teacher / teacher123
  - Студент 1: student1 / student123
  - Студент 2: student2 / student123
============================================================
```

4. **Запустите приложение**

```bash
python app.py
```

5. **Откройте в браузере**

```
http://localhost:5000
```

## 🌐 Страницы платформы

### 1. Лендинг (/)
- Hero-секция с призывом к действию
- Статистика платформы
- Преимущества продукта (6 карточек)
- Витрина клиентов (4 организации)
- Форма для заявок
- Профессиональный дизайн

### 2. Вход в систему (/login)
- Форма авторизации
- Список тестовых аккаунтов
- Ссылка на главную

### 3. Панель администратора (/admin)
- Информация об организации
- Общая статистика
- Управление заявками
- Быстрые действия

### 4. Дашборд преподавателя (/teacher)
- Список созданных работ
- Статистика по каждой работе
- Создание новых работ
- Просмотр выполнений

### 5. Дашборд студента (/student)
- Список назначенных работ
- Статусы и прогресс
- Выполнение работ
- Сдача на проверку

## 📊 База данных

### Таблицы (8 таблиц)

1. **organizations** - организации (колледжи)
2. **leads** - заявки с лендинга
3. **users** - пользователи (с привязкой к организации)
4. **works** - лабораторные работы
5. **steps** - шаги в работах
6. **submissions** - выполнения работ
7. **answers** - ответы студентов

### Демо-данные

**Организации-клиенты:**
- Павлодарский колледж информационных технологий (Premium)
- Astana IT University (Premium)
- Алматинский технологический колледж (Basic)
- Караганда Политехникум (Basic)
- Демо Колледж (Free) - для тестирования

## 🔧 API Endpoints

### Публичные

- `GET /` - Лендинг
- `GET /login` - Страница входа
- `POST /api/login` - Авторизация
- `POST /api/submit_lead` - Отправка заявки

### Защищенные (требуют авторизации)

- `GET /dashboard` - Перенаправление по роли
- `GET /logout` - Выход

### Администратор

- `GET /admin` - Панель администратора

### Преподаватель

- `GET /teacher` - Дашборд
- `GET /teacher/create` - Создание работы
- `POST /api/create_work` - API создания
- `GET /api/work/<id>` - Данные работы
- `GET /api/submission/<id>` - Ответы студента

### Студент

- `GET /student` - Дашборд
- `GET /api/student/work/<id>` - Работа для выполнения
- `POST /api/save_answer` - Сохранение ответа
- `POST /api/submit_work` - Сдача работы

### Файлы

- `GET /uploads/<filename>` - Скачивание файла

## 🎨 Технологический стек

- **Backend:** Python 3.9+, Flask 2.3
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** SQLite (готово к миграции на PostgreSQL)
- **Архитектура:** Мультитенант монолит
- **Стили:** Современный минимализм с градиентами

## 🌟 Ключевые особенности

### Мультитенантность

Каждая организация работает в изолированной среде:
- Отдельные пользователи
- Отдельные работы и данные
- Общая база данных с фильтрацией по `organization_id`

### Система заявок

- Форма на лендинге для новых клиентов
- Сохранение в таблицу `leads`
- Просмотр в панели администратора
- Статусы: новая, связались, конвертирована, отклонена

### Тарифные планы

Готовая структура для монетизации:
- **Free** - базовый функционал
- **Basic** - расширенные возможности
- **Premium** - полный доступ

## 🔒 Безопасность

⚠️ **Важно для продакшена:**

- ✅ Хеширование паролей (bcrypt/argon2)
- ✅ HTTPS
- ✅ CSRF защита
- ✅ Rate limiting
- ✅ Валидация файлов
